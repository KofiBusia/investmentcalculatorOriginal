TWR — Time-Weighted Return

Input: sub-period returns as decimals (not percentages).

e.g. 0.05, -0.02, 0.03

→ means +5%, −2%, +3% in successive periods. Eliminates the effect of cash flows.

MWR — Money-Weighted Return

Input: cash flows. First value = initial outflow (negative), subsequent = inflows (positive).

e.g. -1000, 200, 250, 600

→ Invested GHS 1,000; received GHS 200, 250, and 600 at equal intervals.

Modified Dietz

Input: Initial Value, Final Value, Cash Flow, Weight W

e.g. 155723413.70, 165933966.65, 2784769.61, 0.5

How to calculate W (the cash-flow weight):

W = (Total period days − Days before cash flow) ÷ Total period days

  • Q1 = 90 days. Contribution arrives on Day 30 → W = (90−30)÷90 = 0.667
  • Arrives on Day 45 (midpoint) → W = (90−45)÷90 = 0.5
  • Arrives at very start (Day 0) → W = 1.0
  • Arrives at very end → W = 0.0
  • Timing unknown → use 0.5 (midpoint assumption)

→ Best method when trustees want inflows excluded from performance measurement (GIPS-compliant).

Simple Dietz

Input: Initial Value, Final Value, Cash Flow

e.g. 1000, 1500, 200

→ Assumes all cash flows arrive at the midpoint (W = 0.5 is fixed). Simpler but less precise than Modified Dietz.

IRR — Internal Rate of Return

Input: cash flows. First = initial investment as negative number.

e.g. -1000, 200, 300, 500

→ Assumes equal spacing between cash flows. Same as MWR conceptually; solved numerically.

HPR — Holding Period Return

Input: Initial Price, Final Price, Income/Dividend

e.g. 100, 120, 5

→ If no dividend was received, enter 0 as the third value: 100, 120, 0. Works for any asset.

Annualized Return (CAGR)

Input: Total return (decimal), Number of years

e.g. 0.4726, 0.25  (for a Q1 return of 47.26% over 0.25 years)

→ Enter 0.25 for one quarter, 0.5 for six months, 1 for one year, 2 for two years, etc.

Geometric Mean Return

Input: periodic returns as decimals.

e.g. 0.05, 0.03, -0.02

→ The per-period average compounded rate. More accurate than arithmetic mean for multi-period analysis.

Arithmetic Mean Return

Input: periodic returns as decimals.

e.g. 0.05, 0.03, -0.02

→ Simple average of returns. Used for expected return estimation; tends to overstate multi-period compounded returns.
